Memorama 捲動測試

用手機 Chrome 開，每個連結都做下面五件事，記下有沒有問題
現在的（對照）目前網站上的版本 A　只讓內容區滑動網頁本身不動，只有裡面自己滑 B　回到頂端按鈕往下滑後右下角出現 ↑ 按鈕 C　上方固定列進遊戲後，上方固定重新開始／排行榜／離開 D　開啟時不捲到頂端拿掉打開時的「捲到最上面」 E　D＋停用捲動還原再加上不讓瀏覽器還原上次捲動位置 M1　空白長頁（同遊戲手機設定）沒有遊戲程式，用來判斷是不是 Chrome 的問題 M2　空白長頁（拿掉禁止縮放）同 M1，但沒有 maximum-scale A2　只對 iPhone Chrome 套用內容區滑動其他瀏覽器照舊；拿掉禁止彈回，看下拉重新整理還能不能用

每個連結都做這五件事

  1. 開始頁往下滑到底，再往上滑回最上面
  2. 按進入遊戲，看上方時間、次數、按鈕有沒有被切掉
  3. 遊戲中往下滑再往上滑，最上面回不回得去
  4. 按重新開始，再看一次上方有沒有被切掉
  5. 網址列縮起來又展開時，畫面有沒有跳動
