# Memorama 翻牌記憶

> 中文物品詞彙的翻牌記憶遊戲，含排行榜與兩人模式

- **網址：** https://wangchiapin.github.io/Memorama/
- **Firebase 專案：** memorma-24dab（與 `pop-colores-numeros`、`Ordena-el-Armario` 共用）
- **登入方式：** 匿名登入
- **狀態：** 使用中

## 遊戲模式
- **單人**：可以上排行榜（`memory_game_leaderboard`）。
- **兩人 · 同一台**：輪流翻，配對成功得 1 組並再翻一次；配錯停 1.5 秒後換人。不上排行榜。
- **連線 · 對戰**：兩台裝置，規則同上。用 4 位數房間代碼或連結（`?sala=1234`）加入。
- **連線 · 合作**：兩台裝置輪流翻，共用時間和次數，不分輸贏；每翻完一組（不管配對成功或失敗）就換人，兩人翻的次數一樣多。會記錄雙方各配對成功幾組：遊戲中顯示在玩家欄位，結束畫面顯示在名字旁。
- 連線房間存在 `memorama_rooms/{代碼}`，6 小時後過期；建立新房間時會順手清掉過期房間。
- 每 15 秒報一次在線，對方 40 秒沒消息就顯示「已離線」。

## 開始畫面
- 最上面是名字欄和「進入遊戲」（連線模式則是「建立房間／加入」），設定和遊戲模式在下面。
- 沒有副標，也沒有說明句。

## 設定（每台裝置各自，和其他遊戲共用）
- 字體：繁體（預設）／简体
- 語言：中文＋Español／中文＋English／只有中文
- 拼音／注音：拼音／注音／兩者／關閉
- 語速：慢 0.45／正常 0.65／快 0.85
- 牌上顯示數字：否／是
- 立即生效並記在玩家瀏覽器；切換語速時不會發出試聽聲音
- 拼音、注音、語音一律台灣讀音

## 版面
- 電腦版（寬度超過 1150px）：牌面放大到和右欄一樣高、上下切齊；視窗不夠寬或不夠高時，右欄會自動縮緊。左欄（遊戲紀錄）寬 300px。
- 手機、平板：改為上下排列。

## 其他
- 單人配錯時可直接點下一張牌
- 單人分數存檔失敗會存在玩家瀏覽器，之後自動補送
- GA4：`game_start`、`game_complete`（含 mode）、`room_create`、`room_join`、`leaderboard_view`

## 詞庫（2026-10-27）
- 目前 **96 個**物品詞，寫在 `index.html` 的 `vocab`（欄位：id、emoji、繁體、簡體、拼音、注音、西文、英文）。每局隨機抽 18 組（36 張牌）。
- 編號是 1–100，但 **78 機車、86 地圖、87 悠遊卡、92 球 已刪除**（圖不合用），編號不補，所以中間有空號。程式用 id 找詞和圖，空號沒有影響。
- 讀音以 game-kit 的 GoodTeacher 規則為準（`bank/gt/`）。這次對過，與規則不同、Ben 決定的寫法：
  - 枕頭 zhěntóu（頭念 2 聲）、戒指 jièzhǐ（3 聲）。
  - 鑰匙 yàoshi、掃把 sàobǎ 維持現在寫法（規則表沒有這兩個詞的設定）。
  - 垃圾桶 lèsètǒng 維持教育部標準讀音。
- 西文／英文：棉被 edredón／quilt、帽子 sombrero／hat、口罩 cubrebocas（拉丁美洲用法）、錢包 billetera（墨龍飛天用 cartera，兩邊不同是故意的）。
- 新增詞時：在 `vocab` 加一筆、放對應圖片，注音的音節數要和字數一樣；多音字請對 game-kit 的 GoodTeacher 規則。

## 圖片
`images/images{id}.webp`（300×300）。程式會依序找 `.webp` → `.png` → 顯示 emoji。
51–100 的做法：白底攝影風、單一物品、無文字無人無手；Gemini 產生 2048×2048 後去背，縮到最長邊 252px、置中於 300×300 透明畫布，存 webp（品質 90）。

## 手機瀏覽器備註：捲動後回不到頂端（2026-10-24）
iPhone 版 Chrome 上，頁面可以捲動時，往下捲之後有時回不到最上面（Safari 正常）。
處理方式（已套用在本遊戲）：
- `<meta name="viewport">` 設 `maximum-scale=1`，不使用 `viewport-fit=cover`。
- `<html>` 加 `html{color-scheme:light}`。
- `body` 的 `min-height` 另加 `100dvh`；換畫面（輸入暱稱→進入遊戲等）時把頁面捲回頂端。

手機 Chrome 測試恢復正常；尚未分開測是哪一項有效。新增頁面請照這個寫。
